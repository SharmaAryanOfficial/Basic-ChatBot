# LLM Chatbot

A basic Large Language Model (LLM) chatbot developed to understand the fundamentals of Generative AI, prompt engineering, and conversational AI systems.

## Overview

This project was built as part of my Generative AI internship at **EEGRAB** to gain hands-on experience with LLM-based applications.

The chatbot accepts natural language queries from users, forwards them to an LLM, and displays generated responses through a simple interactive interface.

The primary goal of this project was to understand the complete workflow of building an AI-powered chatbot rather than creating a production-ready application.

## Installation

Clone the repository

```bash
git clone https://github.com/SharmaAryanOfficial/aryan_sharma.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python main.py
```

or

```bash
streamlit run final_app.py
```
